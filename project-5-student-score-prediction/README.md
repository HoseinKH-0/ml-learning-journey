# پیش‌بینی نمره‌ی دانش‌آموز

پیش‌بینی نمره‌ی امتحان بر اساس ساعت مطالعه، با استفاده از Linear
Regression. این پروژه علاوه بر مدل، مفهوم Train/Test Split و ارزیابی
دقت مدل با R² Score رو هم پیاده می‌کنه.

## نکات یادگیری
- تقسیم داده به بخش آموزش (Train) و تست (Test)
- ارزیابی مدل روی داده‌ای که ندیده بود، برای سنجش قابل‌اعتماد بودنش
- محاسبه‌ی R² Score به‌عنوان معیار دقت مدل

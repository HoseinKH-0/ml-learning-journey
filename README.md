# مسیر یادگیری من در Machine Learning

این مجموعه شامل چند پروژه‌ی کوچیکه که در طول یادگیری اولیه‌م در حوزه‌ی
Machine Learning نوشتم. از یه اسکریپت ساده‌ی پیش‌بینی با میانگین متحرک
شروع کردم و به Linear Regression (هم پیاده‌سازی دستی، هم با scikit-learn)
رسیدم.

## پروژه‌ها
1. **میانگین متحرک** - پیش‌بینی ساده بر پایه‌ی میانگین چند داده‌ی اخیر
2. **رگرسیون خطی دستی** - پیاده‌سازی فرمول Least Squares با NumPy
3. **رگرسیون خطی با scikit-learn** - روی دیتاست واقعی دمای ملبورن
4. **پیش‌بینی قیمت خونه** - Multiple Linear Regression روی دیتاست واقعی تهران

# My Machine Learning Learning Journey

A collection of small projects built while learning ML fundamentals,
starting from a simple moving-average predictor and progressing to
Linear Regression (both manual implementation and scikit-learn).

## Projects
1. **Moving Average** - simple prediction based on recent data average
2. **Manual Linear Regression** - Least Squares formula implemented with NumPy
3. **scikit-learn Linear Regression** - on real Melbourne temperature data
4. **House Price Prediction** - Multiple Linear Regression on real Tehran housing data
